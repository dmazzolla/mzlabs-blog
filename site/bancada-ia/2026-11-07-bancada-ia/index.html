Agent Autoloop: tarefas em segundo plano, com perguntas para você decidir. Estreia a Bancada IA: ferramentas abertas para testar, toda terça, quinta, sábado e domingo.

Destaque: Agent Autoloop. Projeto aberto (licença MIT) que agenda tarefas e entrega para agentes de linha de comando como Claude Code e Codex. Segundo o autor, quando o agente pede uma decisão, você recebe um cartão e responde para ele continuar. Roda no Mac e no Linux. Fonte: repositório KKKKhazix/agent-autoloop no GitHub, criado em 03/11.

Poki: servidor MCP e agente abertos para operar um iPhone, sem jailbreak e sem hardware extra. Atenção: segundo o autor, ele manda mensagem e faz pagamento se você pedir, e o conteúdo da tela vai para o serviço de modelo. Fonte: repositório JosssphZhou/poki no GitHub, 05/11.

Kimi K3.1 Pro: a Moonshot abriu os pesos do modelo, com 2,8 trilhões de parâmetros e contexto de 1 milhão de tokens. Segundo a Moonshot, é o seu modelo mais capaz na classe de 3 trilhões de parâmetros. Fonte: cartão do modelo no Hugging Face, 02/11.

Agent Substrate: o Google doou à CNCF, em estágio Sandbox, o orquestrador aberto para rodar agentes de IA isolados (versão 1.0), junto com o gVisor. Fonte: Google Open Source Blog, 05/11.

Agent Autoloop: o agente de linha de comando trabalha em segundo plano.

Um núcleo leve agenda as tarefas e entrega para agentes como Claude Code e Codex. A tarefa chega por horário, por uma issue nova no GitHub ou por um erro do sistema.

Licença
MIT (aberta)
Roda em
macOS e Linux
Criado em
03/11/2026, no GitHub
Destaque · 2 de 3 · como testar

Três passos para ver funcionando.

  • 1Tenha Node 24, Git, curl e um agente de linha de comando já logado.
  • 2Instale pelo script do repositório e rode agent-autoloop try: um teste de ponta a ponta.
  • 3Escreva uma regra no rules.json: o que fazer, para qual agente, em qual pasta.
Destaque · 3 de 3 · cuidados

Quando precisa de você, o agente pergunta.

Segundo o autor, quando o agente pede uma decisão, chega um cartão na notificação do computador e você responde para ele continuar. Enquanto espera, o agente não ocupa processo nem gasta token.

Criado em 03/11; na checagem de 06/11, ainda sem Windows. Teste numa pasta separada antes de dar acesso ao que importa.

Poki: a IA opera um iPhone.

Servidor MCP e agente abertos, sem jailbreak e sem hardware extra. Conecta ao Claude Code ou ao Codex.

Licença
AGPL-3.0
Precisa

Segundo o autor, ele manda mensagem e faz pagamento se você pedir, e a tela vai para o serviço de modelo. No iPhone, só foi validado com a interface em chinês.
