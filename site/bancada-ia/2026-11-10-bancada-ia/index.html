Auto Ontology MCP: perguntas ao banco com verificações no SQL.

Projeto aberto que leva a camada semântica do NVIDIA Auto Ontology para clientes MCP como Claude Code, Codex, Cursor e os apps do Claude e do ChatGPT. Faz duas coisas: responde perguntas sobre o seu banco de dados e guarda uma base de conhecimento pessoal, com os originais no Obsidian.

Licença
Apache-2.0 (aberta)
Modelo
usa o do seu cliente MCP, sem chave de API de LLM
Criado em
06/11/2026, no GitHub
Destaque · 2 de 3 · como testar

Três passos para ver funcionando.

  • 1Instale e ligue o servidor ao seu cliente MCP pelo Quick start do README.
  • 2Rode auto-ontology-mcp demo: ele monta uma loja fictícia com banco de 11 tabelas e 3.200 pedidos, mais três documentos.
  • 3Faça uma pergunta que o banco não cobre. A ferramenta check_answerable aponta o que falta.
Destaque · 3 de 3 · cuidados

Seu time tira número do banco toda semana? Cuidados antes do teste.

O modelo do seu cliente MCP escreve o SQL. O servidor checa a consulta contra a ontologia e os dados e roda só leitura, em arquivos SQLite locais. No exemplo do README, o validate_sql recusa uma junção que diverge da ontologia e mostra a que está cadastrada.

Projeto de 4 dias, ainda sem versão publicada. Comece pela demonstração fictícia. Antes de usar dados internos, confira o que vai para o modelo do seu cliente MCP e as regras da empresa. Revise as definições, as relações entre tabelas e o resultado.

WebsiteBench: o agente consegue refazer um site só navegando?

O agente explora um site em produção pelo navegador e tenta reconstruir uma versão full-stack o mais próxima possível na aparência e no comportamento. São 70 sites e 46.916 casos de teste ocultos. Vai comparar agentes para reconstruir sites? Este benchmark avalia os dois lados.

Mirage: modelo de visão da Cactus que extrai dados de imagens.

Descreve imagens, detecta objetos e responde perguntas sobre documentos. Quem tira dados de foto e documento à mão pode testar com pip install -U cactus-compute. O pacote baixa o motor e os pesos no primeiro uso.
