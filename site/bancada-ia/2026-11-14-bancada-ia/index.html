O llama.cpp chega à versão 1.0.

1/8

O llama.cpp chegou à versão 1.0. É o projeto que roda modelos de IA na sua própria máquina, do notebook ao servidor da empresa.

Destaque: llama.cpp v1.0.0. Saíram juntas as bibliotecas llama.cpp e ggml na versão 1.0.0. Agora uma mudança de versão maior avisa quando a API pública muda de um jeito incompatível. O projeto tem 3,5 anos e suporta mais de 150 variantes de arquitetura de modelo. Fonte: blog do Hugging Face, equipe ggml-org, 13/11.

Granite 4.1 com LLMON: dois modelos experimentais de prévia, de 3B e 8B, treinados numa linguagem de marcação feita para LLMs, que separa instrução de dado. Fonte: blog do Hugging Face, ibm-granite, 12/11.

SGLang-Neuron: a Amazon anunciou que o plugin está disponível ao público e roda o SGLang nos chips Trainium, com a mesma interface. Fonte: blog de machine learning da AWS, 12/11.

BotPsy: a Tether AI Research apresentou um modelo de 0,8 bilhão de parâmetros feito para uso no próprio aparelho, que usa ferramentas em tarefas simples. Fonte: blog do Hugging Face, qvac, 11/11.

Fontes com link no blog: mzlabs.com.br (link na bio).

Destaque · 3 de 3 · cuidados

Seu sistema usa a biblioteca? Olhe o primeiro número.

A partir da 1.0, versão maior nova (MAJOR) indica mudança incompatível na API C pública. Versão do meio traz recurso ou modelo novo. A última corrige erro sem mudar a API.

Os apps de desktop citados são para macOS e Windows. Teste numa pasta separada, com documento fictício e uma tarefa que você consiga conferir. Revise o resultado antes de usar no trabalho.

Granite 4.1 aprende a separar instrução de dado.

Dois modelos de prévia experimental usam o LLMON, linguagem de marcação feita para LLMs. Segundo a equipe Granite, em alguns benchmarks de injeção de prompt indireta estática, o sucesso dos ataques cai para perto de zero. A equipe ainda trabalha nos ataques adaptativos, que se desenrolam em várias interações. Seu agente lê documento de terceiros? Teste com dados fictícios.

Modelos
granite-4.1-3b-LLMON-preview e granite-4.1-8b-LLMON-preview
Para testar
kit no GitHub, com conversor de JSON para LLMON

O SGLang agora roda no Trainium da AWS.

A Amazon anunciou o SGLang-Neuron disponível ao público, num Deep Learning Container. Seu time já serve modelos com SGLang? A interface continua a mesma, com PyTorch nativo por baixo.

Rápida · 11/11/2026

BotPsy: um modelo feito para uso no próprio aparelho.

Modelo de 0,8 bilhão de parâmetros que usa ferramentas em tarefas simples, como agenda, e-mail e arquivos. Segundo a Tether AI Research, supera todo modelo de até 1,2B que ela testou nos seis benchmarks de uso de ferramentas e de agente. Quer avaliar um agente local em tarefas simples? Confira antes se os arquivos já estão disponíveis na fonte. Use dados fictícios e confira para onde cada ferramenta envia informação. O modelo ainda erra e não é para uso de alto risco.

Base
Qwen3.5-0.8B
Formatos anunciados
safetensors e GGUF (bf16, Q8 e Q4)
