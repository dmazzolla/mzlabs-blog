Esse pedido já foi pago? O assistente de IA consulta o SAP.

1/8

Esse pedido de compra já foi pago? Com o SAP Data MCP, o assistente pode buscar o pedido, a fatura e os itens em aberto no S/4HANA. A equipe responsável confere os registros antes de confirmar o pagamento.

Destaque: SAP Data MCP. É um projeto aberto (licença MIT) com servidores MCP para o Claude e outros assistentes consultarem o SAP S/4HANA por RFC/BAPI, por OData de nuvem privada ou pelas APIs liberadas da nuvem pública. Segundo o README, os três serviços somam 412 ferramentas de leitura. As credenciais ficam no arquivo .env local, e o log de auditoria registra os parâmetros de cada chamada. Para investigar um pagamento, o assistente pode consultar o pedido de compra, a fatura e os itens em aberto do fornecedor, conforme os serviços ativos e as permissões. Uma referência de compensação, sozinha, não comprova o pagamento. Faça o primeiro teste em homologação, com dados fictícios e um usuário com permissão apenas de leitura. Fonte: repositório w1ccc/sap-data-mcp no GitHub (20/11).

ERNIE 5.5 Flash Preview: a Baidu abriu os pesos da prévia do modelo, com 280 bilhões de parâmetros, 14 bilhões ativos por token e contexto de 1 milhão de tokens. Licença Apache 2.0. Fonte: cartão do modelo no Hugging Face, 23/11.

safe-anything: um scanner de vulnerabilidades escrito em Rust que roda com um comando só. Na versão consultada, tem 92 regras. Procura SQL injection, XSS, segredos vazados, dependências vulneráveis e falhas na configuração de agentes de IA. Segundo o README, roda sem conta e sem enviar arquivos. A checagem de dependências consulta o OSV.dev, e o modo offline pula essa etapa. Fonte: repositório erkamyaman/safe-anything no GitHub (22/11).

NestJS Agent Skills: são seis skills oficiais do NestJS para agentes de código como Claude Code, Codex e Cursor. Cobrem testes, autenticação, dados e preparação para produção. Fonte: repositório nestjs/agent-skills no GitHub (20/11).

Destaque · 2 de 3 · como testar

Teste na nuvem pública em três passos.

Exemplo do README: S/4HANA Cloud Public Edition, no Windows PowerShell.

  • 1Clone o repositório, crie o ambiente com Python 3.12 e instale o "requirements.txt".
  • 2Copie o ".env.example" para "public_cloud\api\.env" e informe o endereço do SAP. Basic: usuário e senha. OAuth: "SAP_API_AUTH=oauth", URL do token, client ID e client secret.
  • 3Registre o servidor com "claude mcp add" e caminhos absolutos, como no README. Peça ao assistente health_check e test_sap_api_connection(service="material").
Destaque · 3 de 3 · cuidados

Só consulta, sem alterar dados, segundo o README.

O README informa que o serviço RFC aceita apenas 98 funções padrão de leitura. Os serviços HTTP usam pedidos GET fixos, e o único POST serve para obter o token OAuth. As credenciais ficam no arquivo .env local. O log de auditoria registra os parâmetros de cada chamada. O que dá para consultar depende dos serviços ativos no sistema e das permissões do usuário.

A ferramenta não tira conclusão por você. A equipe responsável confere os registros no SAP antes de confirmar se houve pagamento. Uma referência de compensação, sozinha, não comprova o pagamento. O projeto é independente, sem vínculo com a SAP. Faça o primeiro teste em homologação, com dados fictícios e um usuário com permissão apenas de leitura.
